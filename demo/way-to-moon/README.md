# The Way to the Moon — UI/character test

현재 Phaser 게임과 분리된 **짧은 챕터 플레이 테스트**입니다. 시작 화면 뒤 훈련소 전체 샷을 보여주며, 건물을 클릭하면 카메라가 확대되며 해당 공간으로 들어갑니다. 작은 온실에서 장미 돌보기 → 전력 점검을 마친 뒤 전체 지도로 돌아와 달 전망대를 선택하고 관찰 → 엔딩까지 진행합니다. 나머지 건물은 다음 챕터 표시만 있습니다. 화성 온실은 미래의 훈련 장면을 상상한 것이며, 실제 NASA 측정 데이터는 아직 포함하지 않습니다.

## Codespaces

```bash
cd demo/way-to-moon
npm ci
npm run dev -- --port 5174
```

Codespaces **Ports**에서 5174를 엽니다. 원래 게임의 5173 서버는 그대로 둘 수 있습니다.

- 클릭: 시작
- 전체 지도: 건물 클릭으로 구역 선택. 온실 훈련 후 전망대 개방
- `A/D` 또는 `←/→`: 이동
- 물체 가까이에서 `E` 또는 화면의 말풍선 클릭: 상호작용
- 대화창 클릭 또는 `SPACE`/`ENTER`: 대화 넘기기
- `1`/`2` 또는 선택지 클릭: 답 고르기
- `Esc`: 제목 화면으로
- `M` 또는 화면 상단의 전체 지도: 방에서 훈련소 전체 샷으로 복귀

`public/assets/title.png`는 제공된 시작 화면 시안입니다. `campus.png`는 예시 이미지의 건물 배치를 참고해 그린 훈련소 전체 샷입니다. `garden.png`는 제공된 온실 시안에서 UI와 인물을 제거해 만든 게임 배경이며, `observatory.png`는 이어지는 전망대 장면입니다. `prince.png`는 정지 자세, `walk.png`는 4프레임 걷기 애니메이션, `lumi.png`는 안내 로봇입니다. 왼쪽 걷기는 스프라이트의 좌우 반전으로 표현합니다.

이 프로젝트는 7~12세 대상 게임의 UI·캐릭터·대화 흐름을 검증하는 프로토타입입니다. 자원 표시는 게임 내 상태 설명이며 실제 NASA 수치를 의미하지 않습니다.
